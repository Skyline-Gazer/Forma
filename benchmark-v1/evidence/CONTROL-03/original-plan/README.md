## 元数据建议

建议为文档记录下列字段（空值允许，来源需可追溯）：

- `项目编号`、`采购人`、`项目事项`：项目文件关联；通用参考、未确认文件可为空。
- `文档角色`：采购公告、采购技术需求、技术响应、渠道成本报价、项目授权函、交付范围协调记录、内部说明、最终递交确认、模板、产品介绍、未识别扫描件等。
- `版本`、`流程状态`：例如 V0.3/内部审阅、V1.0/批准提交；公告/授权等不适用时为空。
- `形成日期`、`投标截止日期`：分别记录，不能混用。
- `来源方`、`接收方`、`文档编制方`、`投标主体`：避免把厂商、接收方、投标方混成项目归属。
- `保密/用途`：如内部采购成本、内部沟通、对外可提交；按正文明确内容赋值。
- `证据来源`、`识别置信度`、`待核实事项`：特别用于 PDF 扫描/OCR、来源路径与正文冲突时。
- `来源路径/来源批次`：作为溯源元数据，不进入长期物理层级。
