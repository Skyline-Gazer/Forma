## 业务元数据建议

可为每份文档维护结构化字段：`项目编号`、`采购人`、`事项`、`文档类型/业务角色`、`形成方`、`适用范围`（单项目/通用/待确认）、`版本`、`审批状态`、`递交状态`、`敏感级别/用途`（例如内部成本）、`来源`、`解析可信度`。目录保留项目主归属与少量稳定业务角色；版本、状态、形成方等通过元数据筛选，避免目录再按年份/批次/经手渠道继续加深。

Smart Groups 可用查询维度：

- 项目编号等于某编号（分别查看 HC26-041、ED26-073、LG25-019 全套材料）
- 文档类型等于采购公告 / 采购技术需求 / 技术响应 / 渠道报价 / 项目授权 / 递交确认 / 协调记录
- 审批状态等于待审 / 已批准；响应版本等于 V0.3 / V1.0
- 敏感用途包含内部成本
- 适用范围等于通用资料 / 单项目 / 待确认
- 递交状态等于已提交
- 解析来源或可信度等于 OCR 待复核（适用于扫描件；D22 的正文可识别但应保留 OCR 来源标注）
