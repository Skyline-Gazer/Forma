# 原生优先内容感知与回退策略 (`perception-fallback`)

## 1. 感知优先级（Native-First）
1. **WorkBuddy 原生读取与官方办公能力优先**：
   - 对于 `.txt`、`.md`、`.pdf`、`.docx`、`.xlsx`、`.pptx` 及常见图片，优先使用 WorkBuddy 原生 `Read` 工具及客户端内置文档/表格/幻灯片解析能力直接读取内容。
   - 不得假设用户本机预先安装了 `docvortex` 或 `mac-ocr`。
2. **可选外部工具回退（仅当原生读取遇到以下具体缺口时启用）**：
   - **扫描件 PDF / 纯图片文档**：优先使用 WorkBuddy 原生多模态读图；若页数较多或需要离线批量 OCR，再检查环境是否安装 `mac-ocr` 或调用 macOS Apple Vision，并如实记录每页识别状态或不可用原因。
   - **复杂多工作表 XLSX / 原生抽取失败的 PDF**：若 `docvortex` 在当前环境可用，可运行 `docvortex convert --format markdown "<file>"` 获取结构化 Markdown 与表格关系；若未安装且原生能力已足够，则无需强求安装。

## 2. 长文档与证据完整度约束
- **禁止静默截断**：读取长文档时，必须采用**有界分段读取**（先读目录/首页/关键章节，再按需检索相关段落或工作表），不得只读前几行就下结论。
- **证据可追溯**：`draft.json` 中每条整理建议的 `evidence` 字段必须注明依据来源（如页码、工作表名、章节标题或关键摘录位置）。
- **显式失败透传**：遇到加密、损坏、云端未下载（`dataless`）或受限格式导致无法读取正文时，必须将 `disposition` 设为 `review` 并如实标注读取失败原因，禁止猜测内容。
